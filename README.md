# 野狐棋譜スキャナー 1.2.0

Android版「野狐囲碁」の棋譜再生画面をユーザー補助機能で一手ずつ操作し、画面画像から19路盤を読み取ってSGFを作成する新規実装です。対局情報は、ユーザー補助テキストと端末内の日本語OCRを組み合わせて読み取ります。

## 対応環境

- Android 11（API 30）以上
- 縦向きの野狐囲碁・19路盤棋譜画面
- 保存先: 端末の `Download` フォルダー

## 使い方

1. 本アプリの「画面読取を許可」を押し、Androidの確認画面で許可します。
2. 「ユーザー補助を有効化」を押し、「野狐棋譜スキャナー」を有効にします。
3. 「画面上に操作パネルを表示」を押します。
4. 野狐囲碁で対象棋譜を開き、浮動パネルの「開始」を押します。
5. 読み取り完了後、`[黒番]_vs_[白番]_yyyymmdd.sgf` がDownloadフォルダーに保存されます。

パネルは左端の「↕」をドラッグして移動できます。開始時に盤面直下へ自動配置され、読取中も常に表示されます。「停止」または異常終了の場合、不完全なSGFは保存しません。

## v1.2.0の修正

- 画面上部だけを対象にする端末内日本語OCRを追加し、左対局者・中央の手合い／結果・右対局者を個別に拡大認識します。
- ユーザー補助テキストが取得できる場合はその正確な文字列を優先し、不足する名前・級位・勝敗をOCRで補完します。
- 名前行と級位行を座標で分離し、SGFへ `PB` / `PW`（名前）と `BR` / `WR`（級位）として保存します。
- 「中盤勝ち」「投了勝ち」「半目勝ち」「n目半勝ち」と、野狐の `nと分数子勝ち` をSGFの `RE` へ変換します（`1子=2目`）。
- 対局場所を常に `PC[野狐囲碁]` として保存します。
- OCRの初期化または認識に失敗しても処理を止めず、ユーザー補助テキストだけで棋譜読取を継続します。

## v1.1.3の修正

- 初期局面へ戻す際は、画面から手数バーのツマミ位置を検出し、ツマミそのものを左端へドラッグします。
- ツマミが左端に到達したことを画像で確認し、それでも初期局面でない場合に限って「一手戻る」を反復します。
- 黒い最終手マークが重なった白石を空点と誤認し、2手目以降を進められなくなる問題を修正しました。
- 問題画像を「黒1手目から白2手目への局面差分」として読み込み、白の着手を正しく確定できる回帰テストを追加しました。

## v1.1.2の修正

- 既に「絶芸ポイントが不足しています」ダイアログが表示されている場合、文字列と白いモーダル形状の両方から検出します。
- ダイアログ内のボタン座標は一切タップせず、Androidの「戻る」操作で安全にキャンセルします。
- キャンセル後はキャッシュではなく新しい画面画像を取得し直し、自動的に盤面検出・巻き戻し・棋譜読取へ復帰します。
- 通常画面、ポイント不足画面、終局画面を相互に誤認しない画像回帰テストを追加しました。

## v1.1.1の修正

- 手数操作バーの高さ検出が「絶芸復盤」広告の濃紺ボタンを誤認し、巻き戻し操作で広告を押していた問題を修正しました。
- 操作バーの検出対象を、盤面と広告より十分下にある画面最下部の保護領域だけに限定しました。
- 戻る・進む・スライダーの全操作直前に座標を再検査し、安全領域外なら一切タップせず停止します。

## v1.1.0の修正

- 動画で確認された「盤面検出直後にアプリのプロセスが終了する」問題を修正しました。原因だった旧Tesseractネイティブライブラリをアプリから完全に除去しています。
- 対局情報はユーザー補助ツリーのテキストと、画面上の黒白アイコンを組み合わせて取得します。テキストを公開しない野狐バージョンでは不明値を使用し、棋譜保存そのものは継続します。
- 画面が静止して新しいフレームが届かない場合も、直近の正常フレームを利用して処理を継続します。
- 初期局面には手数バーを右から左へスワイプして戻し、必要時のみ「一手戻る」を反復するようにしました。
- 「すでに最後の一手です」は、ユーザー補助イベント、画面テキスト、中央の濃紺バナー画像の三経路で判定します。
- 各手の確定画像から手数バー位置も同時に引き継ぎ、余分な撮影による手順ずれをなくしました。

## 新規設計の要点

- 木目の盤領域を検出し、盤面サイズから19×19交点を算出します。
- 各操作後に同じ石配置を複数回確認してから一手を確定します。
- 期待手番の石が1個増え、相手石だけが取り除かれ得る差分を合法な着手として扱います。
- 盤面不変だけでは終局にせず、「すでに最後の一手です」の文字イベントまたは濃紺バナー画像を確認します。
- 互先・定先は空盤、置き碁は手合いと黒石数が一致する局面を初期局面とします。
- 野狐の「子」表記は `1子=2目` でSGF結果へ換算します。

## ビルド

Android Studioでプロジェクトを開き、`Build > Build APK(s)` を実行してください。JDK 17とAndroid SDK 35を使用します。初回ビルド時には、Google ML Kit日本語文字認識ライブラリの取得が必要です。

## 注意

野狐囲碁の画面配置が将来変更された場合は再調整が必要です。対局日そのものは棋譜画面に表示されないため、SGFの `DT` とファイル名の日付には保存日を使用します。
