# 野狐囲碁スキャナー

## 概要

Android版「野狐囲碁」の棋譜再生画面をユーザー補助機能で操作し、画面画像から19路盤を読み取ってSGFファイルを作成するアプリです。対局者名、級位、手合い、結果などの対局情報は、ユーザー補助テキストと端末内OCRを組み合わせて取得します。保存前に対局情報を確認・編集できます。

## 対応環境

- Android 11（API 30）以上
- 縦向きの野狐囲碁・19路盤棋譜画面
- 保存先: 端末の`Download`フォルダー

## 使い方

1. 本アプリの「画面読取を許可」を押し、Androidの確認画面で許可します。
2. 「ユーザー補助を有効化」を押し、「野狐棋譜スキャナー」を有効にします。
3. 「画面上に操作パネルを表示」を押します。
4. 野狐囲碁で対象棋譜を開き、浮動パネルの「開始」を押します。
5. 読み取り完了後、対局情報を確認・編集し、「保存」を押します。
6. SGFは`[黒番]_vs_[白番]_yyyymmdd.sgf`の名前で`Download`フォルダーに保存されます。

パネル左端の「↕」をドラッグすると、パネルを移動できます。「停止」または異常終了の場合、不完全なSGFは保存しません。

## リリースノート

### v1.5.1β

- Android端末のホームバー／ジェスチャー領域を検出し、棋譜操作バーの検出・操作位置を安全な範囲へ調整しました。
- タブレット端末での盤面・操作バー検出と手合い判定を改善しました。
- ホームバー付近でスライダーや戻る・進む操作が反応しない場合の座標探索とフォールバックを改善しました。
- 対局結果の勝者色を正しく解析するよう修正しました。

### v1.5.0β

- 保存前に対局日時、大会名、対局場所、対局者名・級位、ルール、コミ、勝敗を確認・編集できるようにしました。
- 大会名の既定値を`昇降級戦`、対局場所を`野狐囲碁`、互先のコミを`7.5`、定先のコミを`0`にしました。
- 編集内容をSGFの対局情報へ反映し、入力内容と棋譜の合法性を確認してから保存するようにしました。
- キャンセル時はSGFを作成しないようにしました。
